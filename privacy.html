Privacy Policy

Last updated: 3 October 2026

This page describes the current local AI Shorts workflow and intended TikTok connection. TikTok authorization and video upload have not yet been tested.

Information used

AI Shorts uses the channel identifiers, account information returned by authorized platform APIs, selected video files and associated publishing metadata. An authorized TikTok connection would request basic profile information and permission to upload a video for the creator to finish editing and publishing.

Storage and sharing

Platform credentials and tokens are stored locally outside the project’s Git repository. Selected videos and the information required for an authorized upload are sent to the relevant platform. Project documentation may record channel identifiers and technical upload status, but credentials and tokens are excluded from Git.

This website contains no analytics scripts, advertising or sign-in forms. This website is hosted on GitHub Pages. GitHub processes visitor information, including IP addresses, under its Privacy Statement. Platform processing is governed by each platform’s own privacy policy.

Account access and deletion

The owner can revoke the tool’s access through the platform’s connected-app settings. To request removal of locally stored connection data, contact the email below. Revoking access or deleting local files does not delete videos already sent to a platform; those must be managed on that platform.
